# LexGraph 設計仕様書

TeX で書いた数式をグラフにする Windows デスクトップアプリ。単一 exe で配布し、オフラインで動作する。

- 言語: Rust（edition 2024）／ GUI: iced 0.14（wgpu 描画、使えない環境では tiny-skia にフォールバック）
- 配布物: `target/release/lexgraph.exe`（C ランタイムは静的リンク。VC++ 再頒布パッケージ不要）
- コーディングルール: `cargo fmt` 準拠。clippy は原則対応し、融通のきかない警告のみ `#[allow(...)]` で個別に逃がす
- エラーハンドリング: `thiserror` で型を定義し、`Result` で伝播する

## 第1章 処理の流れ

```
TeX 入力 → core（解析・評価） → render（描画） → app（表示・保存）
```

| 段階 | モジュール | 内容 |
|---|---|---|
| 解析 | `core::parser` | TeX を字句解析・構文解析して `Formula` にする。失敗時は `ParseError`（位置と理由）を返す |
| 評価 | `core::expr` | 式の数値評価と記号微分 |
| 数値解析 | `core::analysis` | 零点・極値・交点の探索、定積分（シンプソン則） |
| 標本化 | `render::sampling` | 式を折れ線にする。不連続点では線を分割する |
| シーン構築 | `render::scene` | 曲線・軸・凡例を、出力先に依存しない描画命令 `Scene` にする |
| 表示 | `render::canvas` | `Scene` を画面（iced canvas）に描く |
| 出力 | `render::export` | `Scene` を SVG にし、SVG から PNG（resvg）と PDF（svg2pdf）を作る |
| 保存 | `app::storage` | `.tgf`（バイナリ）と JSON の読み書き |
| 画面 | `app::ui` | 入力・操作・状態管理 |

式を編集するたびに「解析 → パラメータ検出 → 表示範囲の自動決定 → 標本化・解析 → 再描画」を行う（リアルタイムプレビュー）。

### エラーの扱い

| 型 | 発生元 | 利用者への見せ方 |
|---|---|---|
| `ParseError`（`span` と `ParseErrorKind`） | core | 入力欄の下に赤字で「3文字目「\foo」: 未対応のコマンド \foo です」の形で表示 |
| `RenderError` | render | ウィンドウ下端のステータス行に赤字で表示 |
| `StorageError` | app | 同上 |

ポップアップは使わない。

### 対応する TeX

| 種類 | 書き方 |
|---|---|
| 形式 | `y=...`、`f(x)=...`、式のみ（以上は y=f(x)）、`r=...`、`r(\theta)=...`（極座標）、`(x(t), y(t))`（媒介変数） |
| 演算 | `+ - * /`、`\cdot`、`\times`、`\div`、`^`、暗黙の積（`2x`、`2(x+1)`） |
| 分数・根 | `\frac{a}{b}`、`\sqrt{x}`、`\sqrt[3]{x}` |
| 関数 | `\sin \cos \tan \cot \sec \csc \arcsin \arccos \arctan \sinh \cosh \tanh \log \ln \exp \sgn \max \min` |
| 括弧など | `( )`、`{ }`、`\left \right`、`\|x\|`、`\lfloor \rfloor`、`\lceil \rceil` |
| 定数 | `\pi`、`e` |
| パラメータ | 上記以外の英字とギリシャ文字（`a`、`a_1`、`\alpha`） |

解釈の決めごと:

- `\log x` は常用対数（底 10）、`\ln x` は自然対数、`\log_{b} x` は底 b。
- 上付きは TeX どおり 1 トークンだけを取る。`x^12` は `x^1` の後に `2` が続く扱いで、12 乗は `x^{12}` と書く。
- 括弧なしの関数引数は続く数・変数まで: `\sin 2x` は sin(2x)、`\sin x\cos x` は sin(x)·cos(x)。

### 不連続点の判定

隣り合う標本点の差が大きいとき、区間を半分ずつ狭めて差の変化を見る。急な曲線なら差は縮み、跳びや極なら縮まない。後者でだけ線を分ける。定義域の端も二分法で詰める。

### 保存形式

| 用途 | 形式 | 場所 |
|---|---|---|
| ドキュメント（Ctrl+S） | `.tgf` | 利用者が指定 |
| 前回の状態 | `.tgf` | `%APPDATA%\LexGraph\session.tgf` |
| 保存式と履歴 | `.tgf` | `%APPDATA%\LexGraph\library.tgf` |
| 設定 | `.tgf` | `%APPDATA%\LexGraph\settings.tgf` |
| 保存式と設定のエクスポート／インポート | JSON（`version` つき） | 利用者が指定 |

`.tgf` の構造: マジック `TGF\0`（4 バイト）、バージョン（u16 LE、現在 2）、種別（1 バイト）、本体（postcard）。バージョン 2 では設定に PNG の解像度を追加した。バージョン 1 のファイルも読み込める。

- 自分より新しいバージョンのファイルは読まずにエラーにする。
- 書き込みは一時ファイル経由で行い、途中で落ちても元のファイルを壊さない。
- 読めない `session.tgf` は `session.tgf.bad` に退避してから起動する。

## 第2章 機能一覧

### 入力

| 機能 | 仕様 |
|---|---|
| リアルタイムプレビュー | 入力のたびにグラフを更新 |
| 直打ち入力 | Enter で次の式を追加 |
| 数式パレット | カーソル位置へ挿入。`\sin`・`\log` を先頭に配置。カテゴリ: 基本／三角関数／指数・対数／演算・記号／ギリシャ文字。`\frac{}{}` などは最初の `{}` の中にカーソルを置く |
| エラー表示 | 場所と理由、直し方を入力欄の下に赤字で表示（パレットがあるときはその下） |
| パラメータスライダー | `a`、`b` などを自動検出して生成。最小値・最大値・現在値を数値でも指定可 |

### グラフの種類

| 機能 | 仕様 |
|---|---|
| y=f(x)、媒介変数、極座標 | 媒介変数と極座標は変数の範囲を指定可（既定 0〜2π） |
| 導関数 | 式ごとに破線で表示。y=f(x) は f'(x)、媒介変数は x に対する dy/dx、極座標は r'(θ) |
| 定積分の塗り | y=f(x) の式のみ。範囲は `2\pi` やパラメータも使用可。値も表示 |
| 不連続点 | 線を繋がない |
| 交点・極値・零点 | 自動表示（切替可）。y=f(x) の式のみ。点が密集したときはラベルを間引き、点は残す |

### 表示

| 機能 | 仕様 |
|---|---|
| ホバー座標 | カーソルを合わせたときだけ右下に小さく表示。曲線の近く（14 ピクセル以内）では曲線上にスナップ |
| 色 | 自動割当。パレットまたは `#rrggbb` で手動変更可 |
| 線の太さ・線種 | 式ごとに調整可（実線・破線・点線） |
| グリッド線・目盛り・軸ラベル・凡例 | 既定で表示。個別に切替可 |
| ズーム・移動 | マウスホイールでカーソル位置を中心にズーム、ドラッグで移動 |
| 表示範囲 | 既定は自動決定。数値指定も可。手動で動かすと自動を解除 |
| テーマ | ダークテーマ |

### 保存・出力

| 機能 | 仕様 |
|---|---|
| 式の保存・お気に入り | 名前・タグつき |
| 検索 | 名前・式・タグを対象。空白区切りは AND。お気に入りのみの絞り込み可 |
| 履歴 | 新しい順に最大 100 件。正しく解析できた式だけを記録 |
| エクスポート／インポート | 保存式と設定を JSON で。インポートは保存式を重複なしで追加し、設定は置き換える |
| 自動復元 | 前回の式・表示範囲・ズーム位置・ペイン幅・開いていたファイルを復元。2 秒ごとと終了時に保存 |
| 画像出力 | PNG／SVG／PDF、クリップボードコピー。背景は白（透過はオプション） |
| 解像度選択 | PNG 保存とクリップボードコピーで 800×500、1600×1000（既定）、3200×2000 から選択。選択は設定として保存。レイアウトは 1600×1000 基準のまま拡大・縮小するので、解像度を変えても文字や線の相対的な大きさは変わらない。SVG と PDF は 1600×1000 基準で出力し、この選択の影響を受けない |
| 取り消し・やり直し | 最大 200 手。連続した同じ欄の編集は 1 手にまとめる。表示範囲は取り消しの対象にしない |

### ショートカット（設定画面で変更可）

| 操作 | 既定 | 操作 | 既定 |
|---|---|---|---|
| 新規 | Ctrl+N | やり直し | Ctrl+Y |
| 開く | Ctrl+O | 式を追加 | Ctrl+Enter |
| 保存 | Ctrl+S | 式ライブラリ | Ctrl+B |
| 名前を付けて保存 | Ctrl+Shift+S | 画像を書き出し | Ctrl+E |
| 取り消し | Ctrl+Z | グラフをコピー | Ctrl+Shift+G |
| 表示範囲を自動調整 | Ctrl+0 | 凡例の表示切替 | Ctrl+L |

グラフをコピーの既定キーは Ctrl+Shift+G とする。当初の Ctrl+Shift+C は、開発環境で動作確認した際に C を含むキーの組み合わせがアプリに届かなかった（AutoHotkey による横取りとみられる）ため変更した。旧バージョンの設定で Ctrl+Shift+C のままだった場合は、起動時に Ctrl+Shift+G へ移行する。ただし Ctrl+Shift+G を別の操作に割り当て済みの場合は、元のキーのままにする。

他の操作で使用中のキーへの変更は、どの操作と重なるかを示して拒否する。日本語入力がオンでも動くよう、文字キーは物理キーから判定する。

### 現時点の制限

- 交点・極値・零点と定積分の塗りは y=f(x) の式のみ。媒介変数と極座標は対象外。
- 定積分は、範囲内に関数が定義されない点や無限大になる点があると計算しない（広義積分は非対応）。
- 式の表示は入力した TeX の文字列のまま（凡例も数式組版はしない）。
- 画像の書き出しは画面と同じスレッドで行うため、その間は操作を受け付けない。

## 第3章 画面構成

```
┌──────────────────────────────────────────────────────────┐
│ ツールバー: 新規 開く 保存 | 取り消し やり直し | 式ライブラリ   │
│    | 書き出し コピー □背景を透過 PNG[1600×1000▾]      設定     │
├───────────────────┬┬─────────────────────────────────────┤
│ 左ペイン: 式リスト ││ 右ペイン: グラフ                      │
│ ┌───────────────┐ ││ □凡例 □グリッド □目盛り □軸ラベル      │
│ │▌☑ 入力欄 詳細 ×│ ││ □交点・極値・零点  x[ ]〜[ ] y[ ]〜[ ] □自動範囲│
│ │数式パレット    │ ││ ┌─────────────────────────────────┐ │
│ │エラー（赤字）  │ ││ │凡例                             │ │
│ │スライダー      │ ││ │                                 │ │
│ │詳細設定（▾）   │ ││ │             グラフ              │ │
│ └───────────────┘ ││ │                                 │ │
│ ┌───────────────┐ ││ │                  x = …  y = …   │ │
│ │ 次の式…        │ ││ └─────────────────────────────────┘ │
│ ＋ 式を追加        ││                                     │
├───────────────────┴┴─────────────────────────────────────┤
│ ステータス行（保存結果やエラー）                            │
└──────────────────────────────────────────────────────────┘
```

| 領域 | 仕様 |
|---|---|
| 2 ペイン | 左は式リストのみ、右はグラフ。境界をドラッグして幅を調整でき、幅は次回も復元する |
| 式カード | 曲線の色の帯、表示切替、入力欄、詳細設定の開閉、削除 |
| 数式パレット | 選択中の式の入力欄の直下にドッキング |
| 詳細設定 | 色、太さ、線種、導関数、定積分、変数の範囲、式の保存 |
| 凡例 | グラフ上部に読みやすいサイズ（15px）で表示。幅が足りないときは折り返す。表示／非表示を切替可 |
| 式ライブラリ／設定 | 左ペインを式リストのみに保つため、ツールバーから開く重ね表示にする。Esc または外側のクリックで閉じる |
| 色 | 画面はダーク。出力は背景を白基調にして印刷や資料に使いやすくする |

### デザイン方針

参考資料（Hallmark、Impeccable、SAP Fundamental Styles の Content density）のうち、作業用の画面に当てはまる考え方を取り入れた。配置と操作部品は標準のままにし、独自性は色・文字・密度と、次の特徴的な表現 1 つで出す。

**式カードの左端の帯:** 帯の色は曲線の色と同じで、どの式がどの線かを一目で対応づける。非表示の式では帯を薄くする。

| 項目 | 仕様 |
|---|---|
| 色 | 紺系のインク色を地にする。純黒・純白は使わない。キャンバス→地→カード→操作部品の順に明るくして階層を表し、影は使わない |
| 選択色 | 琥珀。選択中のカード、フォーカス、選択中のタブ、スライダーなどに使う |
| コントラスト | 文字は 4.5:1 以上（本文は 7:1 以上）、入力欄の縁と曲線の色は 3:1 以上。曲線の色は画面と白背景の出力の両方で満たす。`tests/app_theme.rs` で検証する |
| 密度 | マウスとキーボード向けの Compact。余白は 4／8／12、文字は 12／13／15／18 を基本とする |
| 状態 | ホバー・押下・無効をボタンごとに 1 段階で示す。状態が変わっても枠の太さは変えず、表示がずれないようにする |
| 無効表示 | 取り消し・やり直しは、できないときに無効にし、ツールチップで理由を示す |
| エラー | 赤色だけに頼らず ⚠ を付ける。何が問題か、どう直すかを 1 文ずつ書く。入力欄の縁も赤にする |
| 空の状態 | 何が空か、どうすれば埋まるかを示す（グラフ、保存した式、履歴） |

**表示順の変更:** 式カード内は「入力欄 → パレット → エラー」の順とする。パレットを入力欄の直下に固定し、エラーの表示で入力中にボタンが動かないようにするため。
